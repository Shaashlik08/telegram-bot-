# IP2 Final Admin Panel

## Project Description
This project is a Flask-based Admin Panel system for managing student records.

Features:
- Authentication system
- Admin and User roles
- Student records management
- Session-based authorization
- HTML/CSS/JavaScript frontend
- Telegram bot notifications
- JSON database storage

---

## Technologies
- Python
- Flask
- JavaScript
- JSON
- python-telegram-bot
